# Path 7: Planning Team + Expert Skill Library

**This is the current active path we are working on.**

## What This Path Covers

- Building the specialized **Planning Team** (PM, BA, Architect, Research, Design/UX, Meta-Skill roles, etc.)
- Creating and curating a high-quality **expert skill & persona library**
- Finding, evaluating, and adapting the best existing skills and personas from the ecosystem (especially gstack, GBrain, Anthropic, Superpowers, etc.)
- Defining how these skills and personas are used by the CEO Orchestrator, Domain Teams, and subagents
- Starting with the Planning Team as the first major Agent Team to stand up

This path sits at the intersection of:
- The Subagent Model (most Planning Team members will be subagents)
- Domain Operations (Planning Teams operate inside domains)
- Future Self-Improvement (skills and personas should get better over time via dream cycles)
