# Domain Lifecycle Domain Team

**Purpose**: Own the creation, handoff, scoping, and hygiene systems for all strategic domains in CEO Studio projects.

This domain is managed according to the new agent-mediated model it defines (Domain Architect interview, Agenda Agent triage, BA Document Guard protection).

## Core Principles (from the defining vision)
- Domains are created intentionally through structured conversation, not forms or heuristics.
- Nothing is lost: every insight, subdomain, feature, or agenda item is captured during definition.
- Handoffs are first-class, explicit, and human-visible.
- Dirty documents are dangerous. The BA Document Guard prevents work on unverified information.
- Agent scoping is strict. No cross-pollination between System, Project, and Domain agents.

## Current Focus
See `definition.md`, `handoffs/`, and `captured-agenda-items.md` for the live state after initial definition.

## How to Interact
- All new work on domain creation, AGUI outlines, handoffs, or the BA guard should reference this domain's definition and the linked specs in `docs/design/` and `docs/personas/` (inside this domain).
- Major changes require a docs handoff (per root AGENTS.md) and should update the artifacts here.
- The Agenda Agent for this domain owns triage of the initial handoff and subsequent decomposition.
